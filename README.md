# Sablefin Soil Probe — Design Package

Released design package for the **Sablefin Soil Probe, Revision 4** (internal design ID
`SSP-4`).

## What is included
- `hardware/` — KiCad 7 schematic and board source for the probe head and mast adapter
- `firmware/` — STM32L0 application firmware with SHT45 and TDR calibration tables
- `enclosure/` — housing model and print notes for the IP67 enclosure
- `docs/` — bill of materials, assembly steps and field-calibration notes

## Release status
The fabrication outputs in this repository correspond to the SSP-4 pilot batch that
shipped in August 2026. All source files are current; nothing in this package is
pending publication.
